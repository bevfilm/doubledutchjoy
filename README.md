# Double Dutch Joy

Double Dutch Joy is a 2D game about jumping Double Dutch, set in a South Side Chicago neighborhood in the 1980s.

## Core Gameplay

The player jumps rope while collecting "drops," including:
- Lifesaver candies
- Peppermint sticks in pickles
- Other collectible items to be developed

The player must also jump over obstacles such as jacks.

The core gameplay is built around jumping, double jumping, collecting items, avoiding obstacles, scoring points, and surviving as long as possible.

## Current Status

An early playable prototype has been created in GDevelop.

The purpose of this repository is to preserve the original prototype and continue developing Double Dutch Joy toward a polished, playable MVP.

## Development Approach

The existing GDevelop project should be treated as the starting point and reference implementation.

Do not replace or substantially restructure the existing prototype until it has been reviewed and its current functionality has been documented.
